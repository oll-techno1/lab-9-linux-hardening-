Linux Hardening — Automatic Security Updates
============================================

Package: unattended-upgrades

Configuration:
- Automatic security updates enabled.
- Update service and configuration reviewed.
- Dry-run and update execution should be checked.

Verification commands:
sudo unattended-upgrade --dry-run
sudo unattended-upgrade
sudo journalctl -u unattended-upgrades -n 100 --no-pager

Review the actual logs to confirm update execution.
